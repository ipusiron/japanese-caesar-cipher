# 日本語版シーザー暗号（Japanese Caesar Cipher）

日本語（ひらがな）専用のシーザー暗号ツールです。
Webベースで動作します。

**Day 4 - セキュリティツールをAIで作ってみよう 100日チャレンジ**

## 🛠️ 概要

- ひらがなを対象としたシーザー暗号の暗号化・復号ツール
- 並び順を「あいうえお順」「いろは順」「任意」から選択可能
  - 「いろは順」を選んだ場合、「ん」は最後にあるものとします。これで不都合な場合は「任意」を活用してください。
  - 「任意」を選んだ場合、変換対象の文字を指定できます。
- シフト（鍵）を指定して、文字をずらす処理を行う
- 文字の対応関係（平文文字⇔暗号文文字）を暗号表（対応表）として視覚的に表示
- ブラウザー上で完結、インストール不要
- 複数行の文章入力に対応
- ひらがな以外の文字（記号、漢字、カタカナなど）はそのまま出力されます

## 💡 使い方

1. モードを選択（暗号化 or 復号）
2. 並び順を選択（あいうえお順 or いろは順 or 任意）
3. シフト数（鍵）を入力
4. ひらがなを含む文章を入力
5. 「実行」ボタンを押すと、出力結果が表示されます

## ⚠️ 注意点

- 暗号対象はひらがなのみです。それ以外の文字は変換されずそのまま出力されます。
  - 濁点・半濁点・小書き・長音も変換対象としたい場合は、並び順の「任意」を活用してください。
  - よって、文節・語の区切りがそのまま残るため、**暗号文から内容を類推できる可能性があります**。
- 古典暗号としての理解・学習用途に限定してください。
  - 実用的な暗号ではありません。
